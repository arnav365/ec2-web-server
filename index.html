Foundations

About The Project

An in-depth look into the core infrastructure primitives powering modern web hosting on the AWS Cloud.

What is Amazon EC2?

Amazon Elastic Compute Cloud (Amazon EC2) provides scalable computing capacity in the AWS Cloud. It eliminates the need to invest in hardware up front, allowing developers to build, test, and deploy applications rapidly across global regions.

  • Full root / administrative control over Linux OS
  • Flexible instance sizing (e.g. t2.micro / t3.micro in AWS Free Tier)

What is a Web Server?

A web server is software and hardware that uses HTTP (Hypertext Transfer Protocol) and other protocols to respond to client requests made over the World Wide Web. Its primary function is to store, process, and deliver web pages to users.

  • Listens on TCP Port 80 (HTTP) & Port 443 (HTTPS)
  • Maps incoming URI routes to files in /var/www/html/

Why Apache HTTP Server?

Apache HTTP Server is an open-source, battle-tested web server that powers a significant portion of the internet. It is robust, modular, and natively supported across Linux distributions like Ubuntu and Amazon Linux.

  • High stability with predictable configuration via apache2.conf
  • Rich ecosystem of modules for rewrites, security, and SSL

How It Is Served From EC2

When a user enters the EC2 Public IPv4 address into their web browser, the HTTP request traverses the Internet, hits the AWS VPC Internet Gateway, passes the EC2 Security Group on Port 80, and is received by Apache to return the web assets.

  • Seamless zero-delay static delivery directly from disk cache
  • Isolated execution within an Amazon VPC public subnet

Inbound Traffic

Client sends HTTP GET request over public Internet routed through the AWS Internet Gateway (IGW) attached to the VPC.

Security Group Filter

The stateful EC2 Security Group inspects traffic and permits incoming packets destined for Port 80 (HTTP) and Port 22 (SSH).

Content Delivery

Apache web daemon processes the request, loads index.html from the root document directory, and sends HTTP 200 responses.

AWS Infrastructure

AWS Services Utilized

Core AWS cloud building blocks configured to ensure high availability, security, and connectivity.

Core Service

Amazon EC2

Elastic Compute Cloud virtual machine instance (e.g. t2.micro or t3.micro) hosting the Ubuntu Linux operating system and web server stack.

Role: Primary compute & host environment
Network Security

Security Groups

Virtual firewall regulating inbound and outbound traffic. Configured with Inbound Rules for Port 80 (HTTP - 0.0.0.0/0) and Port 22 (SSH - Admin IP).

Role: Inbound & outbound packet filtering
Optional / Planned

Elastic IP

Static public IPv4 address allocated to the AWS account and attached to the EC2 instance to prevent IP address changes during instance stops/reboots.

Role: Persistent public IP address
Network Isolation

Amazon VPC

Logically isolated virtual network with public subnets, route tables, and an attached Internet Gateway enabling bi-directional communication.

Role: Cloud networking perimeter
Deployment Guide

Server Setup Workflow

Step-by-step procedure to provision the EC2 instance, install Apache, and deploy website files.

01

Launch EC2 Instance

AWS Console / CLI

In the AWS Management Console, launch an EC2 instance using the Ubuntu Server 24.04 LTS AMI on a Free Tier eligible instance type (e.g. t2.micro or t3.micro). Create or select an RSA key pair (.pem).

02

Connect Through SSH

Local Terminal

Set correct permissions on your private key file (chmod 400) and connect securely via OpenSSH to the EC2 public IPv4 address.

chmod 400 your-key.pem && ssh -i your-key.pem ubuntu@<EC2_PUBLIC_IP>
03

Install Apache Web Server

Linux Shell

Update the local apt package repository cache and install the Apache2 package daemon.

sudo apt-get update -y && sudo apt-get install -y apache2
04

Start & Enable Apache Service

Systemd

Start the Apache daemon service immediately and configure systemd to start Apache automatically upon system reboot.

sudo systemctl enable apache2 && sudo systemctl start apache2
05

Configure Security Group Rules

AWS Firewall

Ensure the attached Security Group contains an Inbound Rule for HTTP (Port 80) with Source 0.0.0.0/0, and SSH (Port 22) restricted to your IP address.

06

Deploy Website Files to /var/www/html/

Deployment

Transfer website files using SCP or Git clone, and copy contents into Apache's document root directory /var/www/html/.

sudo cp -r index.html css/ js/ assets/ /var/www/html/
07

Access Website Through Public IP

Verification

Open a web browser and navigate to http://<EC2_PUBLIC_IP> to verify the live website rendering.
